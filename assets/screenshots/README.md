# Screenshots

Shown in the top-level README.

- `desktop.png`: desktop Chrome, a terminal running vim on `src/bridge/access.zig` (1294 × 909, the
  page area only, so no address bar).
- `phone.png`: Mobile Safari on an iPhone simulator, a terminal with `git log` and `ls`, the key bar
  at the bottom (1206 × 2622). The address in Safari's bar is blurred.

How they were made (2026-11-26): rweb 0.1.1 behind Tailscale Serve on a Linux host, opened from another
machine, on a throwaway Rex session running plain `bash` with a neutral prompt in an rweb checkout, so
no personal session, host name or prompt appears. In the desktop shot only that session is listed (the
page's list was narrowed in the browser for the picture; nothing else differs from the real page). The
phone's status bar is the simulator's standard 9:41.
